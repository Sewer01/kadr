# Kadr

**Kadr — видеостудия на вашем компьютере.** Картинки, видео, ролики по сценам, монтаж и ретушь. Модели
работают на вашей видеокарте: кадры никуда не отправляются, лимита на количество нет, после установки
интернет нужен только за обновлениями.

Внутри — ComfyUI, но вы его не видите: только понятные поля, прогресс, живое превью и библиотека готового.
Ставить питон, ноды и зависимости самому не нужно: программа делает это сама и честно говорит, что именно
она скачивает и зачем.

> Неофициальный проект сообщества. С компанией MiniMax не связан. MiniMax, H3 и названия моделей принадлежат
> их владельцам.

## Режимы

| Страница | Что делает |
| --- | --- |
| **Видео** | Видео по описанию или по картинке; можно задать первый и последний кадр. |
| **Видеостудия** | Промпт по вашим референсам: до девяти картинок, референс-видео и голос в одной сцене. |
| **Киностудия** | Ролик по сценам: каждая до 15 секунд, следующая продолжает предыдущую. Неудачную сцену
  можно переделать, не трогая остальные. |
| **Экшн-видео** | Драка, погоня, бег: два прохода, второй дорабатывает движение. |
| **Экшн-студия** | То же, но по сценам подряд. |
| **Клип** | Губы под ваше аудио: персонаж говорит или поёт, до 14 секунд. |
| **Актёр** | Диалог и эмоции: стартовый кадр, образец голоса, новые реплики из промпта. |
| **Замена** | Меняет человека в вашем видео на героя с картинки; движение, камера и фон остаются. |
| **Изображение** | Krea 2, FLUX klein, MiniMax H3 Image, Qwen 2.1: картинка по описанию, серия кадров по
  списку промптов, раскадровка, лист персонажа на 4 или 6 видов. |
| **Правка** | Изменить свою картинку словами или по референсам. |
| **Ретушь** | Увеличение видео и фото: быстро (RelayVSR) или качественнее (SeedVR2), прямо на странице, с
  прогрессом. |
| **Монтаж** | Комната на всю ширину: лента кадров, метка, ножницы с обеих сторон, звук со всей ленты,
  склейка, сохранение кадра и куска звука в библиотеку. |
| **Агент** | Вы описываете сцену своими словами — он пишет промпт под нужную модель по вашим скиллам и
  кладёт его в выбранный режим. К сообщению можно приложить видео: программа вырежет из него кадры, и Агент
  увидит, кто в кадре. |
| **Очередь** | Задачи из разных режимов идут одна за другой, результат сам ложится в Библиотеку. |
| **Библиотека** | Всё сохранённое: картинки, видео, звук. Избранное, корзина и перетаскивание прямо в поля
  любого режима. |
| **Модели** | Выбрать другую версию модели и докачать то, чего не хватает. |
| **Настройки** | Папки, отмеченные режимы, аренда мощного компьютера, свои workflow, облако. |
| **О программе** | Что это, откуда выросло, где лежат файлы и кому что принадлежит. |

Плюс шесть цветовых тем, мастер первого запуска под вашу видеокарту, сохранение проекта на середине работы,
подсказки на кнопках и справка под «?» на каждой странице.

## Установка

На странице **Releases** скачайте один файл — **`Kadr-Setup.exe`** — и запустите его. `Source code (zip)` и
`Source code (tar.gz)` GitHub добавляет сам: это исходники для программистов, обычному пользователю они не
нужны.

Windows может предупредить, что установщик не подписан: «Подробнее» → «Выполнить в любом случае».

**Что нужно машине:** Windows 10 или 11, видеокарта NVIDIA от 8 ГБ (комфортно от 16 ГБ) со свежим драйвером —
без него движок не стартует, а программа подскажет и даст ссылку; 32 ГБ оперативной памяти; от 40 до 100 ГБ на
диске, в зависимости от того, какие режимы вы отметили.

### Первый запуск

- **«У меня ничего нет»** — программа сама скачает ComfyUI, ноды и модели. Отмечайте только те задачи, чем
  собираетесь пользоваться: лишнего она не тянет.
- **«ComfyUI уже стоит»** — скачивать нечего. Запустите свой ComfyUI, оставьте адрес `http://127.0.0.1:8188`
  (или впишите свой), отметьте режимы и нажмите «Подключиться». Модели ищутся в любых подпапках по имени
  файла; если ваш файл называется иначе — в «Моделях» есть «Указать файл…».
- **«Компьютер слабый»** — генерация в облаке RunningHub по вашему ключу или аренда сервера с ComfyUI по
  ссылке.

## Куда ложатся файлы

Папку для моделей и данных вы выбираете при первом запуске. Готовые результаты программа дополнительно
копирует в `Видео\Minimax H3\output`: эта копия переживает очистку папки ComfyUI, поэтому Библиотека не
пустеет. Точные пути всегда видны на странице «О программе».

## Обновления

Программа сама смотрит релизы этого репозитория и предлагает установить новую версию — ваши файлы, модели и
история чатов при этом остаются на месте.

## Откуда она взялась

Первая версия выросла из проекта **«Minimax H3 Workspace»** автора
[Yuliya1310](https://github.com/Yuliya1310/minimax-h3-workspace) — спасибо за основу. Дальше программа пошла
своей дорогой, перестала быть обвязкой вокруг одной модели и с версии **2.0.0** живёт в собственном
репозитории: https://github.com/Sewer01/kadr

## Сборка из исходников

```bash
pip install aiohttp pywebview
python app/main.py
```

Установщик собирается PyInstaller (`app/build/h3studio.spec`) и Inno Setup (`app/build/h3studio.iss`).
Версия лежит в `app/version.py` и должна совпадать с `AppVersion` в скрипте установщика и с тегом релиза.

## Из чего состоит

| Файл | Назначение |
|---|---|
| `app/main.py` | окно приложения (WebView2) |
| `app/server.py` | локальный сервер: очередь, библиотека, агент, облако, пути к файлам |
| `app/workflows.py` | графы ComfyUI для всех режимов |
| `app/catalog.py` | какие модели и ноды нужны и как это подбирается под видеокарту |
| `app/engine.py` | определение железа, установка, запуск и обновление ComfyUI |
| `app/monitor.py` | загрузка видеокарты, процессора, памяти и диска для панели слева |
| `app/agent.py`, `app/skills/` | локальный агент и его скиллы |
| `app/cloud.py` | облачная генерация |
| `app/ui/index.html` | весь интерфейс одной страницей |

Сама программа ничего не распространяет: ComfyUI, ноды и модели скачиваются со страниц их авторов (GitHub,
HuggingFace) во время установки. Список, версии и источники — в `app/catalog.py`; лицензии этих компонентов
определяют их авторы.
