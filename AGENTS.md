# Правила работы

- Отвечать по-русски, коротко, простыми словами; файлы без нужды не показывать.
- Проверять кодом и исполнением, не верить логам как факту.
- Работать пакетом; если программа запущена и нужна правка — закрывать без предупреждения.
- Тесты только короткие. Честно признавать ошибки. Без декоративных значков.

## Отчёт в консоль (всегда)

- Перед каждой правкой выводить в консоль краткий отчёт: что делаю сейчас.
- После каждой правки/проверки выводить результат: что прогнало, что нет.
- Формат: одна-две строки, «делаю: ...» / «итог: ...».
